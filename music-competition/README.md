# Echo Music Competition · 로컬 프로토타입

Raha International School Academic Committee의 음악 대회 전용 React + TypeScript + Vite 웹사이트입니다. 수학·영어 대회와 독립된 프로젝트입니다. 화면은 영어이며 설명은 한국어로 작성했습니다.

## 실행

Node.js 20.19+ 또는 22.12+ 권장. macOS 터미널에서:

```sh
cd "music-competition"
npm install
npm run dev
```

터미널이 출력하는 Local 주소(보통 http://127.0.0.1:5173)를 브라우저에서 엽니다. 종료는 Ctrl+C입니다. 기존 npm 캐시 권한 오류가 있는 환경에서는 시스템 권한을 변경하지 말고 `npm install --cache /private/tmp/raha-music-npm-cache`를 사용하세요.

```sh
npm run typecheck  # TypeScript 검사
npm run build      # 타입 검사 후 dist/ 생성
npm run preview    # 빌드 결과 로컬 확인
```

## 페이지와 기능

- Home: 소개, 슬로건, 제안 일정, 장소 미정 표시, 최신 공지, 다음 페이지 버튼
- Competition: 확정 주최·담당자, 학년 풀·형식·공연 조건 검토 초안, 제안 심사표, 확정 상금 배분과 예산·운영 검토 사항
- Registration: 필수값·이메일·분:초 형식 검증, Solo/Group 전환, 그룹 필드와 각 멤버 학년 안내, 학교·학교 담당자 연락처, 입력 내용 미리보기와 수정
- Programme: 명시적으로 표시된 가상 공연 목록
- Results: 실제 결과가 없는 빈 화면과 향후 수상 발표 영역
- Organiser Preview: 가상 신청 목록, 공지 수정, 공연 순서 변경, 데모 초기화, 미구현 결과 게시 상태

URL 해시로 페이지를 이동합니다. `#competition`, `#registration`, `#programme`, `#results`, `#organiser-preview`에 직접 접근할 수 있으며 브라우저 앞/뒤 이동도 지원합니다. 정적 호스팅에 별도 경로 rewrite가 필요하지 않습니다.

## 수정할 위치

- `src/data.ts`: 대회 이름·슬로건·주최·학교·시기·날짜·장소·참가 대상·형식·제안 공연 시간·상금·담당자·규칙·심사 기준, 샘플 공연/신청 데이터 및 최초 공지
- `src/CompetitionDetails.tsx`: 규칙·심사·예산 안내와 재사용 상금 표
- `src/main.tsx`: 페이지 구성과 문구, 폼 항목·검증·미리보기, 운영 데모 상호작용
- `src/styles.css`: 다크/라이트 색상 토큰, 타이포그래피, 모바일 메뉴, 반응형 레이아웃, reduced-motion
- `src/Home.tsx`: Echo 메인 화면, 자체 SVG 공명 그래픽, 참가 학교·안내·공지 구성
- `src/demoRepository.ts`: 데이터 접근 경계. 실제 API가 생기면 이 어댑터부터 교체
- `index.html`: 검색용 설명·기본 제목. 실제 이름 변경 시 이 메타데이터도 함께 수정

`date`와 `venue`는 미정일 때 `null`입니다. 실제 날짜가 확정되면 표시할 날짜 문자열로 바꿀 수 있습니다. 현재는 날짜를 임의로 계산하거나 달력에 넣지 않습니다. 규칙·심사 기준·검토 사항은 구조화된 초안으로 관리합니다. `pools[].awards`는 1·2·3등의 확정 상금이며 0은 No cash award로 표시됩니다. 총액은 자동 합산됩니다. `submissionDeadline`과 `changeDeadline`은 미정이므로 `null`입니다. 형식·심사·운영 사항이 확정되면 해당 페이지의 Draft/Proposed/To be confirmed 문구도 함께 갱신하세요. Home의 큰 슬로건도 `data.ts`의 slogan 값을 읽으며, 첫 단어 뒤 줄바꿈과 마지막 단어 이탤릭을 적용합니다.

## 데이터와 데모 범위

실제 신청 접수, 네트워크 제출, 로그인, 권한 제어, 심사위원 계정, 데이터베이스, 서버 저장은 없습니다. 신청 폼은 React 메모리 안에서만 유지되며 페이지를 떠나거나 새로고침하면 지워집니다. 공지와 샘플 공연 순서 변경은 현재 탭 메모리에만 적용되며 새로고침하면 초기화됩니다. localStorage, sessionStorage, IndexedDB, 쿠키를 사용하지 않습니다. 실제 개인정보 대신 가상 정보로 테스트하세요. 폰트·그림은 외부 서비스에서 불러오지 않으며 공명 그래픽은 자체 SVG 장식입니다. 학교 로고나 참가자 사진을 사용하지 않습니다.

Organiser Preview는 `npm run dev` 로컬 개발 환경에서만 표시되는 데모입니다. 프로덕션 빌드에는 운영 데모 화면·링크가 포함되지 않으며, `#organiser-preview` 직접 접근도 Home으로 표시됩니다. 이는 실제 관리자 인증 구현이 아닙니다. 현재 결과 편집·게시 기능은 의도적으로 미구현 상태이며 실제로 동작하는 것처럼 표시하지 않습니다.

## 실제 운영 전 필요한 작업

1. 상금 배분은 확정 총액 AED 150입니다. 학교 간 학년 대응·참가 학교·혼합 학년 그룹 규칙·시간·날짜·장소·심사 기준·동점 처리·수상 조건과 PAC 역할을 확정하고 문구를 갱신합니다.
2. 개인정보 수집 안내, 학교의 승인·동의 절차, 보관·삭제 정책을 준비합니다.
3. 서버 API와 DB, 서버 측 입력 검증, 접수 기간·중복 접수 정책, 스팸 방지와 오류 처리를 추가합니다.
4. 운영자 인증과 서버 측 권한 제어, 공지·순서·결과 저장/검토/게시 흐름을 구현합니다. 심사위원 계정은 필요한 경우 별도로 설계합니다.
5. 실제 모바일 기기·키보드·스크린리더·학교 브라우저에서 검수하고 운영 데이터로 최종 테스트합니다.

## 나중에 배포하고 학교 서브도메인 연결하기

이번 작업에서는 배포, 유료 서비스 가입, 도메인 구매, DNS 변경을 하지 않습니다.

1. 학교 IT와 사용할 호스팅·서브도메인 및 관리 권한을 합의합니다.
2. 소스 저장소를 승인된 정적 호스팅 서비스에 연결합니다. 프로젝트 루트는 `music-competition`, 설치는 `npm ci`, 빌드는 `npm run build`, 배포 폴더는 `dist`입니다.
3. 임시 배포 URL에서 모든 페이지·폼·모바일 동작과 접근성을 확인합니다. 이 단계에서도 실제 접수 기능은 별도로 구현해야 합니다.
4. 호스팅의 사용자 지정 도메인 설정에 학교가 승인한 서브도메인을 추가합니다.
5. 학교 IT가 호스팅에서 안내한 DNS 레코드(CNAME 또는 A/ALIAS 등)를 등록하고 HTTPS 인증서 발급을 확인합니다. 레코드 값은 선택한 호스팅에서 제공하는 실제 값만 사용합니다.
6. 실제 주소에서 HTTPS·직접 링크·새로고침을 확인합니다. 코드는 현재 도메인을 고정하지 않습니다. Vite `base: './'` 설정으로 하위 경로와 독립 도메인 모두 지원합니다.

## GitHub Pages 배포 준비

저장소 루트의 `.github/workflows/deploy-music.yml`에 자동 배포 설정을 추가했습니다. 상위 폴더의 [DEPLOYMENT.md](../DEPLOYMENT.md)를 참고하세요. GitHub Actions는 상위 저장소 루트에 `.github`와 `music-competition`이 나란히 있는 구조를 사용합니다. 현재 도메인을 코드에 고정하지 않았으며, 도메인 보유 확인 전에는 CNAME을 추가하지 않았습니다. 실제 배포는 GitHub 로그인 후 진행해야 합니다.


## 참가 학교·자유곡 확정 업데이트

`src/data.ts`의 `participatingSchools`와 `repertoire`에 확정 정보를 분리했습니다. Home·Competition·Registration에 공통 반영되며, 학년 대응·혼합 학년 그룹·공연 시간·심사위원 확정과는 구분합니다. KCC와 Gardens의 전체 학교명은 제공되지 않아 임의로 확장하지 않았습니다.


## Echo 디자인 개편

대회명은 **Echo Music Competition**으로 확정했습니다. 기본 화면은 블랙·골드이며 헤더의 Light/Dark 버튼으로 화이트·골드 화면을 전환합니다. 모드는 현재 탭에서 페이지 이동 시 유지되지만 새로고침하면 기본 다크로 돌아옵니다. 테마 선택에도 브라우저 저장소를 사용하지 않습니다. 색상은 `styles.css`의 `:root` / `:root[data-theme=light]` 토큰에서 수정할 수 있습니다.

메뉴의 **Performance Order**는 기존 Programme 페이지이며 `#programme` 링크를 유지합니다. 공개 URL과 저장소 이름은 기존 `music-competition`을 유지하므로 공유 링크가 계속 동작합니다. 대회명, 페이지 제목, 헤더·푸터 및 패키지 이름은 Echo로 변경했습니다.


## 학생 공개 버전

공개 배포에는 Home, Competition, Registration, Programme, Results 5개 페이지만 포함됩니다. Organiser Preview는 Vite의 DEV 조건으로 로컬에만 남겼으며 메뉴만 숨긴 것이 아니라 프로덕션 화면 자체를 제외했습니다. 실서비스 관리자 기능이 필요해지면 서버 측 인증·권한 제어와 함께 별도 구현해야 합니다.
